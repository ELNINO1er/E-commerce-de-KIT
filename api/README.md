# API PHP/MySQL KIC

API de la boutique et du dashboard KIC, conçue pour Apache, PHP et MySQL sur Hostinger.

Elle gère le catalogue, les stocks, paniers, commandes professionnelles, paiements Stripe, clients, promotions, zones de livraison, retours et statistiques. Les données bancaires sont collectées exclusivement par Stripe Checkout.

Consultez `../DEPLOIEMENT-HOSTINGER.md` pour l'installation.
