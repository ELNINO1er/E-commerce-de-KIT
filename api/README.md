# API PHP/MySQL KIC

API de la boutique et du dashboard KIC, conçue pour Apache, PHP et MySQL sur Hostinger.

Elle gère le catalogue, les stocks, paniers, commandes professionnelles, clients, promotions, zones de livraison, retours et statistiques. Aucun paiement en ligne n'est exposé.

Consultez `../DEPLOIEMENT-HOSTINGER.md` pour l'installation.
