# KIC dashboard

Dashboard Angular 21 de KIC. Il consomme `/api`, exige le rôle `ADMIN`, utilise les composants autonomes, Signals et `OnPush`, et se compile pour `/admin/`.

Commandes : `npm start`, `npm run build`, `npm test`.

La boutique publique conserve son design HTML/CSS existant. Aucun paiement en ligne n'est intégré : une commande est validée commercialement par KIC depuis le dashboard.
